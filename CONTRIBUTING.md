# Contributing to AetherSovereignty

## Status

AetherSovereignty is at **Phase 0 (Conceptual Genesis and Methodological Reconstruction Completed)**. The decision is **(E) Undetermined (interim)**. No implementation is planned unless the independence decision becomes positive.

## What contributions are welcome

At this phase, the following contributions are welcome:

1. **Execution of failure conditions** (Phase 3): AS-F1 (Functional Duplication), AS-F2 (Reconstructability), and AS-F5 (Emergent Epistemic Reducibility).
2. **Independent review** of the hypothesis, the four-level stratification, and the falsification plan. (Phase 2 has not started; external review is welcome.)
3. **Citation corrections** — if you find a missing or incorrect reference.
4. **Typo fixes** and minor clarifications.
5. **Threat identification** — additional threats to validity (T8+) not covered by the current register (T1–T7).

## What contributions are NOT accepted at this phase

1. Pull requests adding implementation code (`src/`, `tests/`, `experiments/`). Phase 5 and 6 are not permitted.
2. Specification proposals (`SPECIFICATION.md`). Requires a positive Phase 4.
3. Claims that AetherSovereignty is an independent dimension. The decision is (E); it is not (A).
4. API, schema, or protocol design.
5. Any claim of observable benefit. H-F4 is untested.

## How to Contribute

1. Open an issue describing the contribution.
2. Reference the relevant section of the paper (`paper/AetherSovereignty_Research_Paper_v2.0.0.md`) or the hypothesis document (`ARCHITECTURAL_HYPOTHESIS.md`).
3. Submit a pull request.
4. Wait for review.

## Code of Conduct

Be respectful. Disagreement is welcome; dismissal is not. The investigation is falsification-first, which means the goal is to identify what would count against the hypothesis, not to defend it.

## Falsification-first principle

A contribution that says "this hypothesis is wrong because X" is more valuable than a contribution that says "this hypothesis is right because Y." The former advances the investigation; the latter does not.
