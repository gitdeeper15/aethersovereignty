# 3.5 Four-Level Functional Stratification (Analytical Decomposition)

1. Psychological Decision-Making
2. Decision Authority
3. Normative Authority
4. Sovereignty Architecture

## Methodological Guardrail
The existence of these four conceptual distinctions does not constitute
evidence of an independent architectural entity. They serve strictly as
analytical coordinates to test a core structural dilemma:

Is sovereignty merely an emergent descriptive label for the interaction of
established psychological mechanisms, or does it represent an irreducible
architectural responsibility governing their topology?
